# React + Vite

React + Vite Admin Template (javascript / Style CSS no tailwind CSS)

A modern, clean, and fully responsive React + Vite admin dashboard template. Designed as a starting point for new projects, this template includes a full-featured layout system, sidebar, navbar, authentication pages, Redux state management, and support for themes and languages.

## Features

- Modern, clean, and fully responsive design
- Full-featured layout system
- Sidebar and navbar
- Authentication pages
- Redux state management
- Support for themes and languages

## Installation

```bash
npm install
```

## Usage

```bash
npm run dev
```
